# Smart Campus ERP

Smart Campus ERP is a web-based Enterprise Resource Planning system designed to manage university campus activities through a centralized digital platform.

## Overview

The system connects students, parents, faculty, administrators, and security personnel through role-based dashboards.

## User Roles

### Student
- View profile information
- Track attendance
- Manage fees
- View announcements
- Report incidents
- Access academic information

### Parent
- Monitor student progress
- View attendance
- View fees and announcements

### Faculty
- Manage student information
- Access academic details
- Report campus incidents

### Admin
- Manage users
- Monitor campus activities
- Manage announcements and reports

### Security
- Handle incident reports
- Update incident status
- Maintain campus safety

## Technologies Used

Frontend:
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend:
- Supabase
- PostgreSQL
- Supabase Authentication
- Row Level Security (RLS)

## Features

- Role-based authentication
- Separate dashboards for each user type
- Incident reporting system
- Announcement management
- Student academic tracking
- Responsive design
- Dark and Light mode support

## Deployment

The project is deployed using Vercel with Supabase as the backend service.

## Project Objective

The objective of Smart Campus ERP is to provide a unified digital platform that improves communication, monitoring, and management of campus operations.
